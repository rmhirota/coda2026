Por que geo
Todo dado climático tem coordenada. A pauta mora na relação entre lugares.
Um foco de calor isolado é um ponto. Um foco dentro de uma Terra Indígena, em plena seca, é uma história.
Como cheguei aqui
Na InfoAmazonia, o {sf} virou rotina
O contexto
Cobrir mudanças climáticas na Amazônia é cruzar, todos os dias, coordenadas com territórios.
[Uma pauta concreta que nasceu de um cruzamento espacial]
Por que o {sf}
O dado espacial vira um data.frame. Quem já usa tidyverse já sabe quase tudo.
[O momento em que “caiu a ficha”]
Perguntas que viram pauta
Quatro perguntas espaciais
Dentro de onde?
Quantos focos de calor caíram em cada Terra Indígena.
Quanto?
Quantos km² de alertas de desmatamento há dentro de cada território.
Perto de quê?
O que acontece num raio de 10 km da borda da área protegida.
Em proporção a quê?
Focos por 1.000 km², para comparar territórios de tamanhos diferentes.

Conceito 4 · Operações espaciais
Cruzar atributos ou recortar geometrias
st_join()
O left_join() espacial: cada ponto ganha as colunas da TI em que caiu.
A geometria do ponto não muda. Bom para contar.
st_intersection()
A tesoura: fica só a parte do alerta que está dentro da TI.
A geometria é recortada. Bom para medir área.

Do CSV ao mapa
focos <- read.csv("dados/focos_2024.csv") |>
  st_as_sf(
    coords = c("lon", "lat"),  # x antes de y
    crs = 4326                # WGS 84
  )
 
focos_amazonia <- focos |>
  filter(bioma == "Amazônia")
 
plot(st_geometry(focos_amazonia), pch = ".")
A pergunta
Onde o fogo está?
Atenção
Longitude é o x, latitude é o y. Invertê-las joga a Amazônia no oceano.
Depois carregamos os polígonos com st_read() e st_layers().

st_crs(focos)$epsg    #> 4326
st_crs(tis)$epsg      #> 4674
 
focos_amazonia <- focos_amazonia |>
  st_transform(st_crs(tis))
 
tis_m <- st_transform(tis, 5880)  # metros
 
km2 <- function(geom)
  as.numeric(st_area(geom)) / 1e6
km2(tis_m[1, ])
A pergunta
Minhas camadas falam a mesma língua?
Atenção
Cruzar camadas com CRS diferentes dá erro. Medir em graus dá número sem sentido.

A pergunta
Quais Terras Indígenas concentraram mais focos?
Atenção
É um left join: focos fora de qualquer TI ficam com NA. Não descarte antes de calcular a proporção.
Bloco 3 · continuação
Normalizar antes de ranquear
ranking_tis <- tis_m |>
  mutate(area_km2 = km2(geometry)) |>
  st_drop_geometry() |>
  select(terrai_nom, area_km2) |>
  inner_join(focos_por_ti, by = "terrai_nom") |>
  mutate(focos_por_mil_km2 = n / area_km2 * 1000) |>
  arrange(desc(focos_por_mil_km2))
A pergunta
Qual território queimou mais para o seu tamanho?
Atenção
Número absoluto favorece territórios grandes. A taxa permite comparar.
Bloco 4 · 15 min
Desmatamento dentro das TIs
deter <- st_read("dados/deter/deter_amz.shp") |>
  st_make_valid() |>
  st_transform(5880)
deter_2024 <- deter |>
  filter(format(as.Date(VIEW_DATE), "%Y") == "2024")
 
desmat_em_tis <- st_intersection(deter_2024, tis_m) |>
  mutate(area_km2 = km2(geometry)) |>
  st_drop_geometry() |>
  group_by(terrai_nom) |>
  summarise(desmatado_km2 = sum(area_km2))
A pergunta
Quantos km² de alertas caíram dentro de cada TI?
Atenção
Polígonos inválidos quebram a interseção. st_make_valid() logo na leitura.

Antes de publicar
O dado é o começo da apuração
Foco não é incêndio
É uma anomalia térmica vista por satélite. Um incêndio gera vários focos; use o satélite de referência para comparar anos.
Alerta não é taxa
DETER serve para monitorar; a taxa anual oficial é a do PRODES. Não misture os dois.
Limites têm data
Registre a versão de cada camada e a fase de demarcação das TIs que entraram na conta.
Ouça o território
O mapa aponta onde olhar. Especialistas e quem vive no lugar dizem o que aconteceu.
